Modular Workbench

Build your own synth

Early synthesisers had no fixed signal chain — you built one, live, by running patch cables between modules. Everything you've learned in this lab is a module on this bench. Wire them however you like.

How to patch: add modules, drag them anywhere, then drag from an output port (amber ring) to an input port to run a cable — or click the output, then the input. Drag a cable off to unplug it; click a cable to probe it — the scopes below show that exact point in the chain (click again to return to the Output). Solid green cables carry sound; dashed amber cables are control. Want to write DSP yourself? Add a Code block (under “Build your own”) and press Edit code — your JavaScript runs as a live module. Eject code shows the whole patch as a program. Nothing sounds until a path reaches the Output.

Patching cheat sheet — control, notes & pitch tricks

The LFO wiggles the target's knob, the Envelope shapes it when triggered (hold its Trig button, or gate it from MIDI) — plug it straight into an Osc to gate the note itself, and MIDI In sets an Osc's pitch and fires Envelopes from a real keyboard — pick its channel, or All. No MIDI hardware? The Keys block does the same from your computer keyboard (A–K) or its on-screen buttons, and the Clock block fires gates on its own at a set rate. Note blocks chain too: MIDI In → Latch (notes stay held after you let go — press again to release) → Arp (steps through the held notes at its rate) → Osc/Envelope. Wire a note source into a Filter and its cutoff follows the played pitch — the KT knob sets how strongly. Detune nudges an Osc by cents — two detuned Oscs make the classic fat unison. Sync locks pitch: wire the leader Osc → Sync → follower Osc. Drop a cable on another input to re-route it, or anywhere else to remove it.

For teachers: the bench is open-ended — set patch challenges ("make a wind sound", "build a bass with a filter sweep", "recreate the Synth Lab signal chain") and let students compare patches. Prefer the guided lessons first: Synth Lab covers every concept these modules use. DSP Lab goes underneath them, to the samples. Everything runs offline in a single file using the Web Audio API.
